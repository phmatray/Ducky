# DUCKY007: reserved

**Package:** none. **Surface:** none in Ducky 2.0 (SPEC §16.2).

## What happened

Nothing: Ducky 2.0 never reports DUCKY007. The ID is reserved for a planned Ducky 2.1 analyzer that reports an action
type no reducer, effect or middleware consumes, so the number keeps its meaning when that rule ships.

## How to fix it

There is nothing to fix. If a tool shows DUCKY007, it comes from a newer Ducky than this page describes; check that
version's documentation.
